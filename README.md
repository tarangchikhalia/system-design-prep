# System Design Prep

AI assisted System Design preparation tool

## Overview
System design is a core skill for a software engineer. This tool helps you prepare for system design interviews by providing AI-assisted practice and feedback. User is presented a challenge and must design a solution within a given time constraint.

## Core features
- User can search for system design challenges depending on their skill level.
- User can chat with the system to understand the challenge and get feedback on their solution.
- System can challenge the user with questions based on their solution.
- System provide a mechanism for user to present their solution in form of diagrams or code snippets.

## Tech stack
- Language: TypeScript
- UI: React
- Backend: Node.js
- Database: SQLite
- AI Framework: LangChain
